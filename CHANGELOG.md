## [2.0.0] — 2026-10-02

### Added — Phase 0: Scaffold
- Root CMake build system (C11, CMake 3.25+)
- `clicom` client executable (scaffold)
- `clicom-server` server executable (scaffold)
- `libclicom_common` static library: types, protocol constants, logging, error codes
- `clip_version.h` auto-generated by CMake (software + protocol versions separate)
- CLIPv1.0 protocol definition (`clip_protocol.h`): 36-byte header, TLV payload
- Core type definitions (`clip_types.h`): node identity, channel identity, session,
  PTT floor state with full documentation of architectural decisions
- Error code enum and string table (`clip_errors.h`, `clip_errors.c`)
- Levelled logging with platform-safe timestamp (`clip_log.h`, `clip_log.c`)
- Stub interface headers: `audio.h`, `codec.h`, `speech_analyzer.h`,
  `storage.h`, `security_rules.h`, `security_analyzer.h`
- Default configuration files: `client.conf`, `server.conf`, `security_rules.conf`
- Phase 0 unit tests: version constants, wire constants, enum values, error strings
- Phase 0 startup integration tests: `--version`, `--test` for both executables
- `CMakePresets.json` for Windows MSVC, Windows Ninja, and Linux builds
- `scripts/build_windows.bat` auto-detecting build script
- `tests/scripts/run_local_test.bat` local multi-window test script
- `docs/PROTOCOL_CHANGELOG.md` protocol version history

### Architecture decisions locked
- Node UUID (immutable, server-assigned) vs display_name (mutable, user-chosen)
- Channel UUID (internal) vs join_key (user-facing, e.g. "GC-4821")
- Channel / Connection / Session are distinct concepts
- Channel records persist in SQLite across server restarts
- TLS 1.3 provides all transport security; CRC32 is framing-only
- PTT arbitration is server-authoritative at the channel level
- Server-mediated speech analysis mode (default for v2.0)
- Speech analysis mode disclosed to all members in SESSION_START (mandatory)
- Keyword detection generates advisory SecurityEvent only — no auto-bans
- Admin authentication uses a dedicated credential, server-side validated
